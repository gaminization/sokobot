# 🛡️ Security Policy

## Supported Versions

Currently, the following versions of **Sokobot** are being actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Sokobot very seriously. If you discover any security vulnerabilities, please do not disclose them publicly until we've had a chance to fix them.

**To report a vulnerability:**

1. Report the issue to the repository maintainers via GitHub security advisories or issue tracking.
2. Include clear steps to reproduce the issue.
3. We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress.

### Scope

- Vulnerabilities in the FastAPI backend (e.g., Auth bypass, SQL injection, logic flaws in task allocation).
- Vulnerabilities in the React frontend (e.g., XSS, token leakage).
- We kindly ask you not to perform DoS attacks against production endpoints.

Thank you for helping keep Sokobot safe!
