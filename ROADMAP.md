# 🗺️ Roadmap

Welcome to the **Sokobot** Roadmap! Here is a high-level overview of what we are currently working on and what we plan to build in the future.

---

## 🟢 Current (Q3 2026)
- [x] **Documentation Overhaul:** Improve repository docs (README, INSTALL, API_DOCS, etc.) for a more professional presence.
- [ ] **Predictive Maintenance:** Introduce simple ML models to predict robot battery degradation and maintenance needs.
- [ ] **Advanced Map Editor:** Allow operators to dynamically edit waypoints and charging station locations directly from the UI.

## 🟡 Next Up (Q4 2026)
- [ ] **Multi-Warehouse Support:** Abstract the data models to support multiple warehouse environments within a single deployment.
- [ ] **External Integration Webhooks:** Provide webhook callbacks for task completion and emergency events so external ERP systems can react.
- [ ] **Enhanced Simulation Metrics:** Provide deeper analytical views showing historical bottleneck areas on the warehouse floor.

## 🔴 Future (2027+)
- [ ] **3D Visualization:** Migrate the current 2D warehouse map to a lightweight WebGL 3D view.
- [ ] **Fleet Scaling:** Optimize the backend simulation engine to gracefully handle 10,000+ active robots simultaneously.
- [ ] **AI-driven Allocation:** Replace the current heuristic allocation with an RL-based intelligent dispatcher.

---
*Note: This roadmap is subject to change based on community feedback and operational priorities.*
